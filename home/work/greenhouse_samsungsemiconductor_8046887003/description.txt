What You’ll Do

The Samsung Global Ecosystem Team (GOST) is seeking an intern to develop systems software for memory and storage pools that support reinforcement-learning post-training of large language models. The work will examine how rollout generation, reward evaluation, policy updates, and checkpoint recovery use shared resources. You will build a focused prototype using fabric-attached memory and SSD pool, and measure its effect on training progress, memory pressure, and recovery time.

GOST consists of a geographically distributed group of engineers making high impact contributions both in software and leadership to open ecosystems such as the Linux kernel and QEMU. This work supports Samsung’s latest storage and memory technologies.

As an intern, you will contribute to the SW ecosystem R&D efforts targeting Samsung’s latest memory and storage technologies globally through distributed open-source projects. The goal of the internship is to deliver a working memory-to-storage data path, a live RL post-training demonstration, and a measured explanation of when pooling improves training efficiency or recoverability.

Location: Daily onsite presence at our San Jose headquarters in alignment with our Flexible Work policy

Reports to: Principal Engineer

Responsibilities

- Profile the RL post-training loop to identify memory-capacity limits, data-transfer overhead, storage stalls, and GPU idle time.

- Develop one runtime feature that coordinates bounded memory staging, asynchronous storage writes, prefetching, or capacity allocation across workers.

- Integrate the feature with an existing RL framework using its training and checkpoint interfaces.

- Preserve snapshot consistency, policy-version provenance, buffer ownership, and durable checkpoint publication during asynchronous operations.

- Compare memory-only, storage-only, and combined pool configurations using training throughput, GPU-hours, local-memory usage, and restart performance.

- Deliver correctness tests, reproducible experiments, design documentation, and code suitable for review and potential open-source contribution.

- Find the resource management issue on post-RL workload and resolve the issue in host OS.
